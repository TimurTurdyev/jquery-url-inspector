# jquery-url-inspector

Ловит jQuery-AJAX и показывает адрес с дописанными параметрами.

## Установка

Chrome: `chrome://extensions`, режим разработчика, "Загрузить распакованное".

Firefox: `about:debugging`, "Загрузить временное дополнение", `manifest.json`.

## Настройка

Кнопка в панели, "Настройки": подстрока адреса плюс хвост параметров.

| Ищем | Дописываем |
|---|---|
| `/api/report/` | `no_cache=1&trace` |

Знак `?` или `&` подставится сам.

## Ограничения

Только jQuery, `fetch` и `XMLHttpRequest` мимо. Ждёт jQuery на странице 20 секунд. Висит на всех сайтах, сузить через `matches` в манифесте.

Наружу ничего не уходит, всё в хранилище браузера. Из разрешений только `storage`.
